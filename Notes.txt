First problem: PDO call doesn't work.
Solution:
to enable pdo(database) to work with mysql create info.php with
<?php phpinfo(); ?> 
go the the page (localhost/info.php) and look for the location of ini file.
In this ini file, search for pdo_mysql and remove the ; (at the beginning)

Run
sudo apt install php-mysql

Restart apache
sudo systemctl restart apache2

Verify aht on info.php (refresh) there is entry
API Extensions 	mysqli,pdo_mysql 
============================================================================================================================
